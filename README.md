# Instalation and usage
1. Install latest node js from https://nodejs.org/en.
2. Go into react-app folder and do "npm install"
3. When it's done do "npm run dev" now you may work on react app
4. If you wish to run backend go into api folder and do "npm install"
5. When it's done do "npm run start:dev" and expect green text in the terminal.
